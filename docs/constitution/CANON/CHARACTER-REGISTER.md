## Character record template

For every character, create a separate file or structured record containing:
- exact name and aliases;
- character/identity type;
- owner-authored description;
- visual references and image provenance;
- personality and behavior;
- relationships;
- chronology and appearances;
- quotes and signature expressions;
- source references;
- canon status;
- unresolved contradictions;
- owner approval.

## Important rule

A name appearing in a list does not establish a biography. The current register deliberately preserves unknowns rather than inventing roles.
