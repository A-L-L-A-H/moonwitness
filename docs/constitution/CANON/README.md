## Canon status

- CONFIRMED — explicitly established by the owner or an owner-designated authoritative source.
- SOURCE-FOUND — located in source material; reconciliation may still be needed.
- PROPOSED — new creative material awaiting approval.
- DISPUTED — sources conflict.
- UNKNOWN — insufficient source material.
- SUPERSEDED — replaced, with historical record retained.

## Source discipline

Each entry must preserve exact wording where meaningful, cite source material when available, and distinguish owner-established canon from editorial synthesis. A conversation recollection is useful evidence but may not contain the full original context. A generated visual is not automatically a canonical character design.
