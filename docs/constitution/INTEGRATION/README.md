# Integration Overview

**Status:** PROPOSED  
**Last reviewed:** 2026-11-15

ROCKSOUL DX and MoonWitness are independent products. This folder defines how they may exchange selected material without merging their private and public responsibilities.

## Documents

- [Product boundaries](../MASTER/PRODUCT-BOUNDARIES.md)
- [Integration contract](../CONTRACTS/INTEGRATION-CONTRACT.md)
- [Controlled publishing contract](../CONTRACTS/PUBLISHING-CONTRACT.md)
- [Privacy and data contract](../CONTRACTS/PRIVACY-DATA-CONTRACT.md)

## Initial direction

The only approved conceptual direction is that any future publication from ROCKSOUL DX to MoonWitness must be explicit and user-controlled. No integration is claimed to exist.

Importing public MoonWitness sources into ROCKSOUL DX may be considered later, preserving attribution and source URL.

## Do not build yet

Do not create shared credentials, shared databases, background sync, or public APIs until a concrete use case, threat model, contract version, and acceptance criteria have been approved.
