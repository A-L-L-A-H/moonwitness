# 15 — Migration

Legacy migration is capability-first.

```text
legacy evidence
   ↓
classify capability
   ↓
select canonical owner
   ↓
preserve / extract / adapt / rewrite / merge
   ↓
contract tests
   ↓
decommission legacy path
```

Never copy an entire legacy repository into Gen2 without classification. Legacy adapters are temporary and must have explicit retirement criteria.
