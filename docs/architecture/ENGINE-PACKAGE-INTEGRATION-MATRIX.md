## 2. 16-Addon Runtime Matrix (`packages/addons/*`)

All 16 addons are statically imported in `apps/api/src/bootstrap.ts`, registered in `AddonRuntimeController`, synchronized via `syncModels()`, and exposed through `/_meta/*` and `/api/v1/m/:model` ACLs (`ir_rule`).

| Addon Package                               | Depends On                             | Models (`syncModels`)                                                                             | Runtime Classification & Gap                                                                                                                                                                                                                                       |
| ------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `__base` (`@moonwitness/addon-base`)        | `[]`                                   | `users`, `settings`, `ir_module`, `ir_model`, `ir_field`, `ir_rule`, `ir_view`, `ir_menu`         | **FOUNDATION ENGINE (20 tests):** drives dynamic `AddonRuntimeController`, ACL generic CRUD, metadata studio, and nav tree; lacks `eslint` script & dynamic runtime package loading (static bundle only)                                                           |
| `i18n`, `audit`, `auth`, `timeline`         | `__base` (+ `audit` for `auth`)        | `i18n.*`, `ops.audit_log`, `auth.{user,session,oauth_token}`, `timeline.{event,era}`              | **NATIVE ADDONS:** real domain logic, custom routes, and `@moonwitness/mid` identity store adapter (`auth`)                                                                                                                                                        |
| `canon-lore`, `witness-research`            | `__base` (+ `timeline`/`auth`/`audit`) | `canon.{codex,entity,episode}`, `knowledge.source`, `witness.claim`, `research.run`, `sidra.edge` | **SCHEMA + OVERVIEW/SUMMARY ONLY:** expose IR CRUD + summary/overview GET routes; zero execution pipelines tied to `engines/witness-semantic` or `engines/corpus-srgbl`                                                                                            |
