## 2. Cross-Cutting Platform Integration Matrix

| Dimension                       | `apps/web` (`@moonwitness/web`)                                                                                           | `apps/api` (`@moonwitness/api`)                                                                                                               | `apps/rocksoul` (`rocksoul-dx`)                                                                 | Systemic Assessment                                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **API Contracts & Validation**  | Local helpers + `/_meta/*` views + Zod-less fetch wrappers + Pact consumer spec                                           | Zod schemas in ORM/addons + `/_meta/*` metadata + non-prod Swagger (`/docs`)                                                                  | Local TypeScript API wrappers + Rust Serde structs (`src-tauri`)                                | `@moonwitness/contracts` has `0` consumers; runtime contract drift across proxy/control/desktop boundaries                                               |
| **Auth / OIDC & Sessions**      | `cookie`, `mid-oidc.ts`, `sanctuary-mid-oidc.ts` (`sessionStorage` + BFF)                                                 | Fastify JWT (`mid-jwt.ts`), cookie/session auth (`middleware/auth.ts`), `@moonwitness/mid` (`auth` addon `mid-store.ts`)                      | `await_mid_loopback_callback` PKCE loopback via `@moonwitness/core`                             | Backend identity store converged on `@moonwitness/addon-auth`, but frontend auth UX retains 3 parallel flows                                             |
| **Multi-Tenancy & Isolation**   | None (`0` tenant/workspace switcher)                                                                                      | None (`0` `tenant_id` / `org_id` / `workspace_id` in ORM, addons, or middleware)                                                              | Single-user local workspace SQLite (`project`/`repo` fields are local git/issue labels)         | **P0 P1-blocking gap:** platform is strictly single-tenant today                                                                                         |
| **Data Ownership & Migrations** | Stateless SSR / client state + browser `sessionStorage`                                                                   | Postgres/SQLite via `@moonwitness/orm`: 5 domain dirs migrated to addon `syncModels()`; 9 internal migration lists still in `domain/index.ts` | Local SQLite continuity DB + loopback S3 gateway + Google Drive sync                            | Three separate SQLite/persistence stacks (`apps/api`, `services/memory`, `apps/rocksoul`) lack unified replication or event sync                         |
| **Error Handling & Resilience** | Per-fetch error strings; proxy returns upstream errors without shared envelope                                            | Global Fastify `setErrorHandler` + custom `getEdgeLoopbackErrorPayload` `503` guard + process-local rate limiter                              | Rust `Result<T, String>` + frontend retry/toast wrappers                                        | In-memory rate limiter in `fastify.adapter.ts` does not share state across multiple API instances                                                        |
| **Build, CI & Deployment**      | Next.js container (`Dockerfile`), port `3000`; tested in `ci.yml` (`lint`, `typecheck`, `109` Vitest, Playwright configs) | `tsup` bundle (`dist/index.js`, `noExternal: [/^@moonwitness\//]`), port `3002`; tested in `ci.yml` (`162` Vitest)                            | Vite frontend (`62` Vitest in CI) + Tauri Rust (`20` `.rs` files **NOT built or tested in CI**) | `services/storage/Dockerfile` missing from disk despite `docker-compose.yml` `--profile ops` build reference; `services/memory` absent from Compose & CI |
