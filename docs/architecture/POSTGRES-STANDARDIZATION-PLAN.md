# PostgreSQL-Only Standardization Plan & Persistence Inventory (`MW-0805` / `#288`)

> [!IMPORTANT]
> **Owner decision (2026-11-19):** PostgreSQL is the sole approved database engine across MoonWitness cloud (`apps/api`, `packages/mid`, optional `services/*`), local development/testing, and private local companion apps (`apps/rocksoul`, `services/memory`), with strict trust-zone isolation. Binary files, archives, and model weights remain filesystem/object-storage payloads.

## 2. Non-Database Assets (Remain Files / Object Storage)

- Original ChatGPT/Claude ZIP/JSON archives and source exports (`services/memory`).
- ROCKSOUL git worktrees, generated diffs, and local artifacts (`apps/rocksoul`).
- Object payloads in `services/storage` (`data/objects/` or Google Drive backend).

## 3. Controlled Migration Waves

1. **Wave A (Done / In Progress):**
   - Fail-closed `DATABASE_URL` production guard (`apps/api/src/shared/env.ts`, `PR #390`) and `/api/v1/readyz` optional `ops` readiness reporting (`apps/api/src/interface/routes/health.routes.ts`).
   - Optional `ops` service readiness & deterministic `503 SERVICE_DISABLED` gates (`packages/addon-runtime/src/upstream.ts` — `isOptionalOpsServiceEnabled`, `getDisabledOptionalOpsErrorPayload`, `probeOptionalOpsServices`, `#284`).
   - PostgreSQL backup/restore CLI + multi-DB backup-set completeness/freshness verification (`scripts/backup-db.mjs` `--verify-set` & `verifyBackupSetManifest`, `#192`).
   - Zone C local `apps/rocksoul` execution hardening: bounded process supervisor, `SAFE_ENV_ALLOWLIST`, and startup stale-run recovery (`apps/rocksoul/src-tauri/src/commands/agent_execution.rs` — `reconcile_stale_agent_runs`, `#282`).
2. **Wave B (`services/*` — IMPLEMENTED):** `radius`, `snmp-poller`, `syslog`, and `storage` enable `sqlx` `postgres`/`any`, provide `is_postgres_url` + `init_postgres_pool` (`sqlx::migrate!("./migrations").run(&pool)`), and bind dedicated PostgreSQL databases (`radius`, `snmp`, `syslog`, `storage`) with `depends_on: postgres: service_healthy` under `--profile ops` in `docker-compose.yml` (`PR #519` + `vps-topology.test.ts`).
3. **Wave C (Zone C Local PostgreSQL & Centralized Addons — IMPLEMENTED):** Loopback-only `validate_private_postgres_url`, `pgvector` HNSW metadata DDL (`POSTGRES_SCHEMA_STATEMENTS`), and non-destructive SQLite reconciliation helpers (`export_sqlite_reconciliation_manifest` in `apps/rocksoul/src-tauri/src/db.rs`, `export_sqlite_reconciliation_counts` in `services/memory/backend/app/db.py`) are enforced alongside `packages/orm` live PostgreSQL API conformance (`PR #518`).
