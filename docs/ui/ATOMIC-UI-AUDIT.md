## 4. Skin, DNA & Theme Architecture Audit

1. **Four Disconnected State Mechanisms**:
   - `SkinRoot` / `SkinScope` (`skin/dna-worlds.tsx`): Sets `data-dna="<MasterDnaId>"` and inline `--dna-*` CSS vars; provides `DnaWorldContext` (`useDnaWorld()`). Does **not** set `data-skin`, `data-theme`, or interact with `SkinProvider`.
   - `SkinProvider` (`skin/index.ts`): Reads/writes `localStorage.getItem('mw-skin')`; manages `SkinName` (`default | riot | editorial | technical | archive | transmission`); does **not** write any `data-skin` attribute to DOM or sync with `--dna-*` variables.
   - `useThemeMode()` / `applyThemeMode()` (`skin/index.ts:82-128`): Writes `data-theme="dark|light"` on `document.documentElement`. **`BROKEN` in SSR**: line 97 & line 125 call `window.matchMedia(...)` unconditionally during render when `mode === 'system'`, throwing `ReferenceError: window is not defined` under Node/SSR! Also lacks a `MediaQueryList` `'change'` listener when OS theme changes at runtime.
   - `applyTheme()` (`dna/registry.ts:112-123`): Injects `:root` CSS vars into `<style id="mw-theme-variables">` in `<head>`. Independent of both `SkinRoot` and `SkinProvider`.
2. **`Skinned.*` Fake Component Wrapper (`skin/index.ts:153-205`)** — **`BROKEN`**:
   - `createSkinComponent(componentName, skinName)` renders `React.createElement(as || 'div', ...)` for **all** components (`Skinned.Button`, `Skinned.Input`, `Skinned.Card`, etc.), violating native button/input semantics (`Skinned.Button` renders a `<div>`) and emitting dead CSS class names from `skinBaseClasses()` (`"riot riot default"`, `"default default default"`) that match **no rules** in `base.css`, `theme.css`, or `dna-base.css`.
3. **`skin/effects.ts` Invalid CSS Class Output** — **`BROKEN`**:
   - `halftone()`, `grain()`, `cmykSlip()`, `duotone()`, `tape()`, `sticker()`, `brushUnderline()` return raw multi-property CSS declaration / pseudo-element strings (`"position: relative; &::after { ... }"`), NOT utility classes. `skin/compositions.ts` merges these strings into CVA variants, emitting unparseable junk into React `className` attributes.
4. **Duplicate `buttonVariants` (`skin/variants.ts` vs `components/ui/button.tsx`)** — **`DUPLICATED`**:
   - `skin/variants.ts` exports `skinButtonVariants` (`variant` + `size` + `skin`), never imported by `components/ui/button.tsx`.
   - `components/ui/button.tsx` has its own `buttonVariants` with hardcoded `#fff6df`, `#f0e5cf`, `#d6b46c` literals and no `skin` axis.
