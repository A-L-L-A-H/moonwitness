# MoonWitness Documentation Ownership Matrix

## 1. Purpose

This matrix operationalizes Section 5 of [DOCUMENTATION_GOVERNANCE_CONTRACT.md](./DOCUMENTATION_GOVERNANCE_CONTRACT.md) across every concrete directory in `A-L-L-A-H/moonwitness`. Ownership follows **workspace co-location**: no maintainer outside the owning boundary may silently redefine a scoped specification without cross-owner review.
