# Focused architecture contracts
These complement [BLUEPRINT](../../BLUEPRINT.md), not competing blueprints. [App/runtime ownership](APPS.md), [ORBIT spatial frontend](ORBIT.md), [LUMEN agent runtime](LUMEN.md), [ECHOLOG storage surface](ECHOLOG.md), [id/en localization](I18N.md), [App Factory](FACTORY.md), [Publication/security](SECURITY.md), [Release/Coolify](RELEASE.md). D19 is accepted for ECHOLOG; D20 (ISP/network operations) was withdrawn by [ADR-0019](../decisions/ADR-0019-withdraw-isp-vertical.md) and D18 Messages & Channels left for the standalone MOONSKY repository ([ADR-0020](../decisions/ADR-0020-skylink-withdrawal-to-moonsky.md)), so this repository keeps no messaging service, no second SQL owner and no D18 contract — `@moonwitness/moonql` is the only SQL owner. ECHOLOG has content-addressed filesystem storage and a bounded S3-compatible subset; consumer/operator UI/end-to-end gates remain open. ORBIT is an accepted planned frontend boundary under ADR-0004/M40, not a backend or domain owner. LUMEN under ADR-0010/M41 is an accepted framework/worker architecture boundary, not implementation evidence. Code/test evidence and [TODO](../../TODO.md) remain authoritative.
