# 07 — Artwork Prompt Library

Use these prompts as production starting points. Keep the R!OT visual bible consistent across batches. The prompts intentionally avoid famous artist names, existing mascots, and third-party brand marks. Adapt image aspect ratios and output sizes to the target tool.

## Global style prefix

Append this style direction to relevant prompts:

> Original R!OT OS visual identity, CHAOS BRUTAL GRUNGE GEN Z FUNKY, underground photocopied punk-zine energy fused with brutal editorial graphic design, industrial control-room symbolism, comic-book/manga motion language, strange playful original characters, strong silhouette, ink-black and paper-white foundation with acid-lime and signal-orange accents, tactile xerox grain, halftone, torn-paper collage, rough marker strokes, imperfect print registration, deliberate asymmetry, premium art direction, crisp composition, high visual impact, no stock-vector look, no imitation of an existing artist or franchise.

## Global negative prompt

> No existing brand logos, no copyrighted characters, no celebrity likenesses, no watermark, no stock-photo look, no generic SaaS dashboard, no beige minimalism, no random unreadable UI text, no fake words, no gibberish typography, no low-resolution blur, no duplicated subjects, no extra limbs, no malformed hands, no muddy low contrast, no overexposed neon glow, no excessive gradient fog.

## p5.js sketch implementation prompts

For each sketch, ask the coding agent to implement a standalone, seedable p5.js sketch with a small typed config and an export helper. Use a stable seeded PRNG rather than unseeded `Math.random` for the art layout.

- `xerox-turbulence`: draw layered low-frequency and high-frequency noise with sparse dust, controlled by seed/intensity.
- `manga-speedlines`: generate radial, diagonal, or directional line fields, with a configurable focal point and safe margins.
- `halftone-field`: calculate a responsive grid of dots/shapes with density and angle controls.
- `signal-glitch`: generate separated horizontal signal bands, displacement blocks, and controlled chromatic offsets.
- `ink-splatter`: create seeded organic blobs/splatter with bounded point count and vector-like edge forms.
- `acid-orbit`: draw eccentric orbit paths, nodes, rings, and short-lived pulses without constant high-frequency motion.
- `industrial-waveform`: render grid lines, telemetry traces, tick marks, and a waveform with configurable motion.
- `chaos-grid`: build a modular grid and selectively break, offset, rotate, and emphasize cells while preserving composition.
- `paper-rip`: create deterministic irregular edge contours with a clean clip/export boundary.
- `crosshatch-ritual`: produce intersecting hand-drawn hatch strokes with density and direction controls.
- `static-creature`: create abstract creature-like silhouettes from constrained organic geometry; seed must keep shape stable.
- `riot-poster-engine`: compose a background from selected primitives, texture layers, safe typography areas, and a seeded focal subject.

## Batch-generation procedure

1. Create a character reference sheet before character poses.
2. Generate no more than one coherent family per batch; compare outputs side by side.
3. Reject image batches with character drift, muddy palette, unreadable composition, or repeated silhouettes.
4. Record the exact prompt and generation settings in a neighboring `.prompt.md` or the manifest.
5. Integrate a small selection first; do not dump every output into the interface.
