# R!OT OS — Local AI Master Kit

This kit gives a local coding agent the project mission, architecture contract, visual DNA, artwork-production system, execution rules, and a verifiable TODO list.

## Install into the repository

1. Make a backup or commit your current work first.
2. Extract the ZIP into the **root of the R!OT OS repository**, merging the `.riot-ai/` folder. The archive includes a root `AGENTS.md`; if the repository already has one, merge the instructions rather than overwriting repository-specific rules.
3. Open the repository root in your local coding agent.
4. Give the agent this exact first message:

```text
Read AGENTS.md and every file listed in its Mandatory reading section. Treat them as binding project instructions. Inspect the actual repository and current Git state before editing. Then execute .riot-ai/10-TODO.md from P0 to P3, not just plan it. Build R!OT OS as a premium monorepo template with a strong CHAOS BRUTAL GRUNGE GEN Z FUNKY art direction. Produce and integrate original SVG, PNG, and p5.js artwork according to the asset manifest. Preserve working behavior, use shared reusable components, validate every phase, and record evidence in .riot-ai/12-LOCAL-AI-REPORT.md. Do not commit or push.
```

## Important

The ZIP is an instruction and execution kit, not a claim that the application has already been migrated or that artwork has already been generated. The local agent must create the deliverables, integrate them, test them, and update the report with evidence. If its environment lacks image-generation capability, it must still create the SVG and p5.js artwork it can produce, clearly list the PNG items it could not generate, and never mark those items complete.
