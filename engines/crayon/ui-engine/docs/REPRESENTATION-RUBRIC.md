# CRAYON Representation Experiment Rubric

A representation survives because it preserves meaning and agency, not because it looks fashionable.

Every Lab experiment must be evaluated on the same semantic fixtures and against these dimensions.

## Truthfulness
- Is epistemic state visible/addressable?
- Can unknown/conflicted information be mistaken for fact?
- Can prediction be mistaken for observation?
- Can historical state be mistaken for current truth?

## Proportional attention
- Does semantic gravity track decision significance?
- Does low-value activity overwhelm high-consequence meaning?
- Is uncertainty intensity proportional to decision relevance rather than alarm aesthetics?

## Orientation
- Can a person identify the current semantic anchor?
- Does stable context survive state change and semantic zoom?
- Are related contexts distinguishable from the current subject?

## Consequence before commitment
- Are material effects available before commitment?
- Does high resistance force sufficient disclosure?
- Can styling or compact mode hide an irreversible/material consequence? If yes, reject.

## Explainability
- Can Inspector explain availability, authority, resistance, physics, and temporal state?
- Are physics scores accompanied by deterministic reasons?

## Accessibility / modality parity
- Is critical meaning present as text/semantics and not only color, geometry, or motion?
- Does Text/Agent/Voice preserve truth/actionability/witness claims?

## Witness
- Are prediction, observation, reconciliation, and historical witness distinct?
- Is unresolved retry state visible?
- Does later evidence append rather than rewrite history?

## Cross-domain reuse
An experiment must survive multiple unrelated fixtures without domain-specific branches in RIR/physics. At least Banking, Files, Communication, Operations, Approval, and AI should be exercised before a visual convention is treated as general.

## Automatic audit
`auditRepresentation()` checks a minimum machine-enforceable subset: orientation, epistemic truth, consequence presence, authority requirements, disclosure for material paths, explained physics, and witness/history structure.

Automatic pass is necessary but not sufficient. Human review should still reject technically valid representations that obscure orientation, overstate certainty, or reduce CRAYON to a generic dashboard/activity feed.
