# CRAYON v0.1.0-alpha.1

**Release date:** 2026-08-24  
**Status:** Architectural alpha checkpoint

## What this release is

`v0.1.0-alpha.1` freezes the first executable CRAYON semantic + agency kernel.

It proves that CRAYON can model a domain-independent loop for:

`Observation -> Knowledge -> Situation -> Possibility -> Intent -> Prediction -> Commitment -> Guarded Execution -> Observation -> Reconciliation -> Witness`

without embedding React, browser, button, card, modal, or domain-specific concepts into the kernel.

## P0 — Truth and epistemics

Included:

- observation/evidence semantics;
- epistemic knowledge with unknown/uncertain/conflicted states;
- prediction separated from observed reality;
- reconciliation and freshness reasoning;
- witness history that later evidence cannot rewrite;
- retry safety for ambiguous external outcomes;
- transition preconditions and stale-prediction detection;
- architecture guards against UI/platform/domain leakage.

Review: `docs/P0-REVIEW.md`.

## P1 — Agency and execution safety

Included:

- independent authority capabilities: observe, propose, intend, commit, execute, verify, override;
- explicit scoped allow/deny rules;
- unknown never becomes implicit allow;
- deterministic constraints;
- possibility availability derived from current knowledge + authority;
- human/agent/service authority separation;
- authentic commitment records;
- validated execution preparation;
- transition/possibility consequence binding;
- deep-frozen process-local execution permits;
- start-time world revalidation;
- one-shot execution permits;
- stale permit permanent invalidation;
- authentic `ExecutionLease` before execution observations are accepted;
- execution output as observation/evidence rather than trusted `success=true`.

Review: `docs/P1-REVIEW.md`.

## Why this is alpha

This release intentionally does not claim:

- production security certification;
- distributed execution trust;
- crash-safe persistence;
- cryptographic permit/witness integrity;
- complete cross-domain falsification;
- mature consequence/risk policy;
- RIR;
- Web Renderer;
- CRAYON Lab;
- final Visual DNA;
- autonomous self-generating UI.

The current process-local capability mechanism is a semantic safety prototype. Distributed execution will require a stronger verifiable trust mechanism.

## Validation note

P0 reached a compiled local 14/14 test checkpoint. During P1, GitHub Actions CI was intentionally disabled during rapid iteration; targeted local type/runtime checks and adversarial fixtures were used while hardening authority and execution semantics.

This release is therefore an **architectural alpha**, not a production release.

## Next

The next implementation path is intentionally short:

1. P2 consequence/commitment hardening.
2. Minimal RIR.
3. Minimal Web Renderer.
4. CRAYON Lab preview using the same semantic situation.
5. Expand falsification across Banking, Files, ERP, Email, DevOps, and AI.

This lets CRAYON begin generating visible semantic interfaces early while preserving the kernel invariants frozen here.
