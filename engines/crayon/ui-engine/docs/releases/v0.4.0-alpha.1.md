# CRAYON v0.4.0-alpha.1 — Cross-domain Representation + Inspector

## Release intent

This alpha is the first checkpoint where CRAYON must preserve the same semantic representation grammar across multiple unrelated application domains while explaining *why* the representation exists.

The release is deliberately not a finished design system. It advances the proof that CRAYON can derive representation from meaning without embedding domain-specific UI code.

## New public package

- `allah-crayon-inspector`

The Inspector consumes Situation + Semantic Snapshot + RIR and returns renderer-independent explanation for semantic source, actionability, consequence resistance, and representation physics.

## Minimum representation physics

`allah-crayon-physics` now includes deterministic explainable:

- `gravity()` — significance / attention pull;
- `distance()` — semantic proximity;
- `depth()` — disclosure / evidence demand;
- `trace()` — durable outcome-trace demand.

RIR nodes may carry these scores with textual explanations. The scores remain semantic inputs to renderers; they are not colors, spacing, CSS, or component variants.

## Cross-domain falsification

The same Snapshot → RIR → Inspector pipeline is tested against:

1. Banking transfer
2. File deletion / trash
3. Email send
4. ERP approval
5. DevOps deployment
6. AI proposed change

The RIR planner is tested for absence of domain-specific branching vocabulary.

## Developer experience

Two runnable public-package examples are included:

```bash
npm run example:semantic
npm run example:inspect
```

CRAYON Lab is upgraded to a six-domain microscope with live Snapshot / RIR / Inspector / text views.

## Release gate

The release is accepted only after the self-hosted runner passes:

- strict TypeScript verification;
- complete Node regression + falsification suite;
- six-domain invariance tests;
- CRAYON Lab production build;
- runnable consumer examples;
- npm package ownership/name checks;
- six `npm pack` artifacts;
- fresh-project installation and public API import smoke test.

## Non-goals / limitations

- final Visual DNA is not frozen;
- gravity/distance/depth/trace are minimum models, not final calibration;
- voice/agent renderer invariance remains later work;
- distributed execution trust, persistence, cryptographic witness integrity, performance budgets, and full security certification remain deferred;
- APIs remain alpha and may change.
