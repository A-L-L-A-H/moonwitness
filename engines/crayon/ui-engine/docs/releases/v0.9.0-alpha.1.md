# CRAYON v0.9.0-alpha.1 — Durable Runtime + Production Hardening

Status: verified main code candidate; external publication/live-deployment evidence remains incomplete.

## Release meaning

`v0.9.0-alpha.1` moves CRAYON from a living semantic/representation prototype toward a production-shaped engine without declaring the experimental APIs stable.

The public npm release set remains eight packages. Durability, adapters, codecs, runtime helpers, observability, renderer expansion, localization, redaction, and Lab engineering utilities remain private experimental workspaces until beta API review.

## Added

### Durable runtime
- TemporalStore reference boundary and append-only temporal journal.
- Deterministic replay/restore preserving unresolved outcome state.
- External operation identity + idempotency semantics.
- Observation ingestion with source/receivedAt/evidence/reliability policy.
- Canonical Snapshot/RIR envelopes, resource limits, and explicit migration registry.
- Crash-recovery decisions that never resurrect an execution lease.
- Async external executor that always treats transport completion as semantic outcome `unknown`.
- Compensation/corrective-action plan as a new possibility linked to the prior transition.
- Tamper-evident journal integrity-chain experiment with explicit non-authenticity limitation.

### Integration
- Domain Adapter SDK/conformance boundary.
- Banking, Files, Email, ERP, DevOps, and AI reference adapters.
- Transport-neutral observation connector contract with duplicate/late/out-of-order semantics.
- Reason-code catalog and drift check.

### Renderer maturity
- Required semantic-claim conformance kit.
- Terminal, Static HTML, and Print experimental projections.
- Localization/RTL boundary preserving semantic IDs.
- reduced-motion/high-contrast/forced-colors renderer contract.
- `allah-crayon-react/safe` degraded mode representing renderer failure as SYSTEM LIMITATION rather than domain outcome.

### Lab / developer experience
- Declarative scenario tooling, temporal frame projection, semantic RIR diff, evidence graph, and diagnostic profiler.
- URL-addressable Lab scenario/theme/detail/Inspector state.
- screenshot matrix, accessibility browser smoke, and Web bundle budget.
- create-CRAYON starter template, adapter cookbook, API entrypoint drift checks, package smoke, and public examples.

### Security / compatibility / release
- structural redaction boundary.
- deterministic adversarial/property corpus.
- codec byte/depth/collection/object resource limits.
- compatibility fixtures and canonical acceptance corpus.
- dependency/license/SBOM-style release inventory.
- npm provenance flag in publisher.
- release-set guard validates private-workspace dependencies against the exact public release version.
