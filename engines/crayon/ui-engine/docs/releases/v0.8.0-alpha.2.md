# CRAYON v0.8.0-alpha.2

**Release theme:** Dark Flagship + Light Companion without semantic drift.

This checkpoint does not introduce a second semantic system. It proves that one Situation → Snapshot → Physics → RIR → Renderer pipeline can support two distinct visual atmospheres while preserving truth, consequence, authority, resistance, uncertainty, and witness.

## Added

- Dark Flagship as the default CRAYON Lab visual identity.
- Light Companion as a persisted alternative for daytime, enterprise, documentation, and print-oriented contexts.
- Theme selection through renderer/Lab visual tokens; Kernel, Snapshot, Physics, and RIR remain theme-independent.
- Theme-aware Web renderer color variables for background, surface, text, lines, accent, availability, uncertainty, danger, and witness/reconciliation treatment.
- Keyboard-accessible theme selector with `aria-pressed` state.
- Pre-render theme initialization to avoid semantic UI flashing through the wrong theme.
- Paired real screenshot capture for Banking desktop dark/light plus additional Deploy/mobile proof.
- `docs/VISUAL-THEME-CONTRACT.md` defining visual invariants.
- `docs/SHOWCASE-CONCEPTS.md` separating generated expectation imagery from executable Lab screenshots.
- Regression tests that fail if Dark/Light theme names leak into Kernel/RIR semantics.

## Invariant

Theme changes may affect atmosphere, contrast, glow, elevation, and visual token values. Theme changes may not affect:

- observed/known/unknown truth;
- actionability;
- consequence;
- authority requirement;
- commitment resistance;
- predicted vs observed distinction;
- witness history;
- semantic zoom guarantees;
- renderer authority.
