# CRAYON Engine

The engine is intentionally **epistemically conservative**: it organizes supplied observations, evidence, patterns, actors, meanings, actions, benefits, and cautions; it does not silently invent missing facts.

## No Empty Level Rule

Each RGBL level must yield something explicit:

- **R1 Reality → Information**
- **G2 Governing Order → Knowledge**
- **B3 Being → Understanding / Meaning**
- **L4 Light → Wisdom / Responsible Direction**

When a level is unsupported, the engine emits `UNKNOWN — ...` with the missing requirement.

This makes absence of evidence visible rather than hiding it behind fluent prose.
