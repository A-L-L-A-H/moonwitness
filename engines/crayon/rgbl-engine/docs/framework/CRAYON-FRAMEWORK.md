# CRAYON SIN-CAN Framework

## Orientation

CRAYON SIN-CAN is presented in this project as a universal-language framework shaped by the project's understanding of divine guidance and mercy: the door to learning, return, repair, and responsible action remains open to human beings without declaring every action correct.

The framework therefore separates **human capacity** from **the correctness of a claim or action**.

> Human imperfection does not automatically cancel human capacity.

## RGBL

```text
R1 — Reality          → Information
G2 — Governing Order  → Knowledge
B3 — Being            → Understanding / Meaning
L4 — Light            → Wisdom / Responsible Direction
```

The levels are cumulative:

```text
R
R + G
R + G + B
R + G + B + L
```

A later level may reinterpret an earlier level, but it must not erase the underlying evidence without explanation.

## No Empty Level Rule

A CRAYON analysis is incomplete when a color is only named but produces no explicit yield.

If support is missing, record `UNKNOWN` and state what information is required. The method prefers visible uncertainty over fluent invention.

## Final loop

```text
CONTEXT
→ REALITY
→ ANALYSIS
→ WHY
→ OUTPUT
→ NEXT
→ BENEFIT + RISK
→ LEARN
→ REPEAT
```

SIN-CAN runs across that loop:

```text
SIN → UNDERSTAND → CAN → ACT → LEARN → RETURN
```
