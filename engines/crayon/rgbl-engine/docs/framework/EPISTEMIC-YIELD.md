# Epistemic Yield

CRAYON requires an explicit product from every RGBL level.

| RGBL | Required yield | Main question |
|---|---|---|
| R1 Reality | **Information** | What is present / observed / sourced? |
| G2 Governing Order | **Knowledge** | What pattern or relation is supported? |
| B3 Being | **Understanding / Meaning** | Who/what is involved and what does it mean? |
| L4 Light | **Wisdom / Responsible Direction** | What integrated lesson and action follow? |

## Full transformation

```text
INFORMATION
→ KNOWLEDGE
→ UNDERSTANDING / MEANING
→ WISDOM
→ RESPONSIBLE ACTION
→ FEEDBACK TO REALITY
```

## UNKNOWN is valid output

When support is insufficient:

```text
UNKNOWN — collect the missing information
```

is better than inventing a plausible-sounding answer.

This is the **No Empty Level Rule** and a core engine invariant.
