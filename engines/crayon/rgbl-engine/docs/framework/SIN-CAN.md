# SIN-CAN

## Meaning

**SIN** is the recognition of an imperfect state: error, harm, risk, limitation, contradiction, unresolved condition, or a situation treated as wrong within the relevant domain.

**CAN** is the remaining possibility: understand, learn, repair, change, create, choose differently, or produce something beneficial.

> **SIN does not cancel CAN.**

## Human interface

The visual memory hook is:

```text
OUT OF LINE
→ WADUH
→ LOOK
→ UNDERSTAND
→ CAN
→ COME BACK
→ ACT
→ LEARN
→ DRAW AGAIN
```

The wrong loop is:

```text
SIN → LABEL → JUDGE → STOP
```

The constructive loop is:

```text
SIN → UNDERSTAND → CAN → ACT → LEARN → RETURN
```

## Non-exclusion principle

CRAYON does not require a person to be perfect, expert, already correct, or free from failure before participating in inquiry and improvement.

However:

> **CAN ≠ automatically RIGHT.**

Claims and actions still pass through reality, reasoning, consequences, ethics, benefit, and caution.

## Mercy and responsibility

The project uses mercy as an entry principle: error does not automatically close the possibility of return and learning.

Responsibility remains: consequences, repair, and truth are not erased by mercy.

**Mercy keeps the door open. Responsibility tells us to come back.**
