# RGBL v7 API

The canonical `createCrayonEngine().analyze()` result keeps `epistemicYield` and reports `researchStatus` alongside the v0.8 formal `rnd` audit layer.

Research utilities exported from `engine/src/index.ts` include `validateStudyCase`, `validateAnnotationRecord`, `agreementReport`, `cohenKappa`, `repeatedRunStability`, `assessCausalChecklist`, `compareHypotheses`, `feedbackTransition`, `temporalActionGate`, `DOMAIN_EPISTEMOLOGY`, `checkEpistemicAdmissibility`, `calibrationReport`, `decisionGate`, `detectHoldoutLeakage`, `summarizeArms`, `RGBL_V7_RELEASE`, and `auditResearchMaturity`.

These utilities provide research instrumentation. They do not convert synthetic tests into empirical evidence.
