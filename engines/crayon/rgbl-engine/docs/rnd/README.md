# RGBL Research Specification

The research stack preserves the canonical four RGBL levels/yields and makes the method increasingly auditable.

- v0.8: formal boundaries/transitions/provenance/uncertainty/diagnostics.
- v0.9: empirical study and annotation design.
- v1.0: reliability/agreement metrics.
- v2.0: causal/hypothesis/counterfactual discipline.
- v3.0: temporal feedback and action consequence.
- v4.0: domain epistemology/source admissibility.
- v5.0: uncertainty decomposition/calibration/decision thresholds.
- v6.0: comparative/holdout/adversarial evaluation infrastructure.
- v7.0: integrated governance and stable research-engine release.

Start with [`RESEARCH-MATURITY-v7.md`](RESEARCH-MATURITY-v7.md). v7 is stable software/specification; empirical validation remains a separate research gate.
