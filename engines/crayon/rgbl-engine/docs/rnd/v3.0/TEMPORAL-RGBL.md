# RGBL v3.0 — Temporal RGBL & Feedback

RGBL is iterative:

```text
Reality(t0) → RGBL(t0) → Action(t0) → Consequence → Reality(t1) → RGBL(t1)
```

L4 is therefore **responsible direction under current support**, not a final truth state.

## Action record
Every consequential action should record expected outcome, reversibility, risk, and observation window.

## Feedback
A proposed action does not complete `L4 → R1'`. The transition becomes observed only after a later Reality state records consequences.

High-risk irreversible actions require higher support or a stop/information-gathering response. Reversible tests are preferred when uncertainty remains and experimentation is ethically/domain appropriate.
