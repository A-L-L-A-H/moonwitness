## What is stable
The canonical RGBL contract remains:

```text
R1 Reality          → Information
G2 Governing Order  → Knowledge
B3 Being            → Understanding / Meaning
L4 Light            → Wisdom / Responsible Direction
```

v7 integrates claim boundaries/transitions/provenance; UNKNOWN/conflict/per-level confidence; failure diagnostics; empirical study schemas; reliability metrics; causal/hypothesis discipline; temporal feedback/action safety; domain epistemology; uncertainty/calibration/decision thresholds; comparative/holdout/adversarial benchmark tooling; and governance that separates stable release from scientific-validation claims.

## What release does NOT mean
v7.0 does not assert external scientific validation, theological proof by computation, or universal superiority over other reasoning methods. Those claims require empirical data and independent evaluation.

## Mandatory release rule
The v7 research head is promoted from `dev` to `main` only after strict compile/tests and synthetic development checks pass. `main` and `dev` should point to the same release commit immediately after promotion.
