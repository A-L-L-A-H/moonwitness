# Contributing

## Framework invariants

Contributions should preserve these core rules unless a versioned framework change explicitly revises them:

1. R1 = Reality → Information.
2. G2 = Governing Order → Knowledge.
3. B3 = Being → Understanding / Meaning.
4. L4 = Light → Wisdom / Responsible Direction.
5. RGBL is cumulative.
6. Missing support is recorded as `UNKNOWN`, not silently invented.
7. Quality Check includes evidence, alternatives, reasoning, confidence, and caution.
8. SIN-CAN keeps possibility open without declaring all actions correct.
9. Benefit and caution remain visible at the end of the loop.
10. Domain-specific source types must remain explicit.

## Code

Run:

```bash
npm install
npm run build
npm test
```

Add tests when changing engine behavior.

## Media

Use Git LFS for large media. Avoid committing duplicate renders or temporary files.
