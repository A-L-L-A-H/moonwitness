# ADR 0003 — Bible as Witness Container

**Status:** Accepted

The modern label `Bible` may be used only as a library/container label for extant textual witnesses. It is not a revealed-source ID in the engine.

- Torah/Pentateuch witnesses can support the `TAURAT` source layer.
- Psalms witnesses can support the `ZABUR` source layer with attribution metadata.
- Gospel witnesses can support the `INJIL` source layer with transmission/language metadata.
- Other Biblical books are not silently imported into one of the four source categories.
