# Bible Witness Docs

The Bible is treated as a **modern witness-container label**, not a source ID.

Read `BIBLE-WITNESS-CONCEPT.md` for the normative rule.

Approved conceptual mappings remain source-specific:

- Torah/Pentateuch witness → `TAURAT`
- Psalms witness with attribution metadata → `ZABUR`
- Gospel witness → `INJIL`

No other Biblical book is imported automatically.
