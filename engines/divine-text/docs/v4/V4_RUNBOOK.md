# v4 Runbook

No dependency install is required.

```bash
npm run check
npm run cli -- quran:verify
npm run cli -- quran:search الله
npm run cli -- identity injil
npm run cli -- score 18 22 17 15 13
npm run cli -- report
npm run serve
```

API: `/api/health`, `/api/quran/verify`, `/api/quran/search?q=...`, `/api/report`.
