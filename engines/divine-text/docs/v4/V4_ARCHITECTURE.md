# Divine Text Verification Engine v4.0

Zero-dependency Node.js (ESM) research runtime. JavaScript only in the executable layer.

## Core rule
**Revelation claim != text identity != textual preservation != historical evidence != interpretation.**

## Runtime modules
- Quran corpus verifier/search
- bounded evidence scorer
- claim/identity graph baseline
- manuscript register
- local report builder
- CLI
- local JSON API

## Evidence policy
Missing corpora remain `PENDING`; they never become zero and never receive invented scores.
