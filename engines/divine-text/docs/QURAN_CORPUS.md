# Qur'an Corpus

The repository now contains a local Uthmani Quran corpus extracted from the installed TeX Live `quran` package (`qurantext-uthmani.def`).

- Records: 6,236 ayat
- Format: JSONL
- Each record includes surah number/name, ayah number, and Uthmani text.
- The source file header states LPPL licensing.
- This local witness is **not** represented as a Tanzil download. It is kept as a reproducible local corpus and must be cross-checked against the project's selected authoritative digital source before publication.

Tanzil describes its Uthmani text as a Unicode encoding of the Medina Mushaf; repository-level comparison can therefore be added as a separate audit stage.
