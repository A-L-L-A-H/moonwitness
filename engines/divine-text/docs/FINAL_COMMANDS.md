# Final Local Commands

## Start the local research UI

```bash
npm run start:all
```

Then open `http://localhost:8787/`.

## Download corpora

```bash
npm run corpus:download:all
```

## Verify corpus hashes

```bash
npm run corpus:verify
```

## Run all automated checks

```bash
npm run audit:full
```

## Start deterministic autopilot

```bash
npm run autopilot
```

The UI also exposes `DOWNLOAD ALL MISSING` and `VERIFY / HASH` under Corpus.
