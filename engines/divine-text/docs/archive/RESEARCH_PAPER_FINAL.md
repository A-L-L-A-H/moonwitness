# Divine Text Verification Engine

## Abstract
This project defines a source-critical framework for comparing revelation claims, transmitted texts, manuscripts, canonical structures and interpretive traditions across Abrahamic textual traditions. It explicitly separates theological claims from historical and textual evidence.

## Research Questions
1. What does each tradition explicitly identify as revelation?
2. What surviving texts are proposed as representations of that revelation?
3. What manuscript and transmission evidence exists?
4. Where are the links between revelation claim and surviving text strong, weak or unresolved?
5. Which claims are textual, historical, theological or interpretive?

## Method
The project uses a common evidence schema, source levels L0–L7, and a 100-point evidence score. Scores are withheld when required fields are missing.

## Case Studies
- Muhammad / Quran / Hadith
- Musa / Torah
- Dawud / Zabur / Psalms
- Isa / Injil / Gospels
- Bible canon and manuscript traditions

## Limitations
The framework cannot numerically prove metaphysical divine causation. It can evaluate provenance, textual evidence, transmission, historical proximity and interpretive distance.

## Expected Output
A reproducible dataset of claims, passages, witnesses and evidence assessments rather than a single 'winner' score for a religion.
