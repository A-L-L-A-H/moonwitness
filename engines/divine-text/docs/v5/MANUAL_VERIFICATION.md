# Manual Verification Protocol v5.1.1

Numeric score is allowed only when all five evidence components have documented basis.

## Auto-safe
- direct source classification already explicit in the source
- corpus lookup and indexing
- checksum/provenance
- deterministic score arithmetic

## Human verification required
- identity of a surviving text with a named revelation
- manuscript dating interpretation
- substantive textual variants
- high-impact contradiction findings
- claims that depend on contested historical attribution

## Rule
PENDING and UNRESOLVED are distinct from zero. They must never be converted to a numeric score by the AI.
