# Divine Text Verification Engine v3.0

## Purpose
A research system for separating revelation claims, transmitted texts, manuscripts, interpretation, and historical evidence across Quran, Hadith, Torah/Pentateuch, Psalms, Gospels, and Bible canon traditions.

## v3 layers
1. Source registry
2. Local corpus normalization
3. Claim/evidence records
4. Passage linking
5. Variant classification
6. Manuscript register
7. Canon modeling
8. Evidence scoring
9. Cross-scripture identity analysis
10. Research reporting

## Data-integrity rule
Missing source files remain `PENDING`. A registry entry is never treated as a local corpus.

## Key research distinction
`Revelation claim != text identity != textual preservation != interpretation`

## Current local corpus
- Quran normalized JSONL: 6,236 records.
- Hadith: pending external file ingestion.
- Torah/Psalms/Gospels: external-register baseline only.
