# @moonwitness/eslint-config

Shared ESLint 9 flat configuration presets for MoonWitness workspace packages and applications.

## Presets (`package.json` Exports)

- `.` / `./base` -> `./base.js`
- `./node` -> `./node.js`
- `./next` -> `./next.js`
- `./react-internal` -> `./react-internal.js`
- `./api` -> `./api.js`
