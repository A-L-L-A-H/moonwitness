# @moonwitness/typescript-config

Shared strict TypeScript configuration presets extended across monorepo packages and applications.

## Presets

- `base.json` — Strict `ES2022` / `NodeNext` base preset (`strict: true`, `noUncheckedIndexedAccess: true`, `noImplicitOverride: true`)
- `nextjs.json` — Preset for Next.js applications (`apps/web`)
- `react-library.json` — Preset for React UI libraries (`packages/ui`)
- `vite.json` — Preset for Vite frontends (`apps/rocksoul`)
