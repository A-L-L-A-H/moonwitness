# @moonwitness/addon-runtime

Odoo-inspired runtime controller, `ir_*` model/view/menu registry, tenant-scoped generic CRUD (`/m/:model`), `_meta/*` introspection APIs, capability manifest signing, and `ops.job` queue backing `@moonwitness/addons` and `@moonwitness/api`.

- `./runtime` -> `./src/runtime.ts`
- `./ir-models` -> `./src/ir-models.ts`
