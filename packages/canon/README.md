# @moonwitness/canon

Canonical domain types, codex core structures, narrative/epistemic helpers, organization/sovereign models, and engine metadata exports shared across applications (`0.1.0`).

## Modules (`src/index.ts`)

Re-exports `./types`, `./codex-core`, `./narrative`, `./epistemic`, `./organization`, `./sovereign`, `./mtime-engine`, `./divine-text-engine`, and `./research-engines`.

## Scripts

```sh
pnpm --filter @moonwitness/canon lint       # eslint src
pnpm --filter @moonwitness/canon typecheck  # tsc --noEmit
pnpm --filter @moonwitness/canon test       # vitest run (index.test.ts)
```
